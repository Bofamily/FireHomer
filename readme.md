# FireHomer
FireHomer allows you to set your homepage in Firefox

# Download
Download the [latest release](https://github.com/Bofamily/FireHomer/releases/latest)

# Install
Open the downloaded `.xpi` with Firefox to install (If you downloaded it with Firefox it should ask you if you want to install)
